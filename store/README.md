# store/ — материалы для RuStore и сайта gornitsa.games

## Новый кабинет RuStore (ИП), 20.10.2026

Владелец оформил ИП и завёл новый аккаунт разработчика RuStore на ИП. По документам репозитория «Анамнез» в
прежнем кабинете (физлицо) не заводился — карточка создаётся сразу в новом; если черновик там всё же есть, пакет
может оказаться занят — сверить в консоли. Сейчас — **только карточка с предзаказом**:
1.0 ждёт проверки названия по ФИПС (что держит — ниже). От РСЯ игра не зависит: рекламы в ней нет и в 1.x не
будет; RuStore Pay тоже не нужен — покупок нет.

**Приложение в консоли заведено** (20.10.2026): «Анамнез — симулятор врача», номер **2063773259**
(`https://console.rustore.ru/apps/2063773259`). Шаг 2 сделан; шаг 1 (ФИПС) — за владельцем; дальше — с шага 3.

1. **Название.** Перед созданием — поиск «Анамнез» по базе ФИПС (классы МКТУ 9 и 41) и по RuStore
   (`12-publishing.md` §2, §8). Найдётся похожий знак — не заводить карточку, написать агенту: название
   на карточке сменить можно, пакет — нет. Приложение уже заведено, а ФИПС — за владельцем (fips.ru из среды
   разработки закрыт): до этой проверки PR выпуска 1.0.0 не готовится.
2. **Новое приложение** в консоли: тип — игра; пакет — `games.gornitsa.anamnez` (`app.json`, ADR
   [0015](../docs/adr/0015-ci-build-signing.md)). Пакет вечный: с другим именем игру уже не обновить. Если консоль
   просит APK уже при создании — `anamnez-N.apk` из последнего релиза `vX.Y.Z` на странице Releases (сейчас
   [v0.6.7](https://github.com/Nefeste/anamnez/releases/tag/v0.6.7)): он подписан постоянным ключом, SHA-256
   сертификата `873b866f…fd3db4` — консоль запомнит этот ключ для всех следующих версий. Сверить в консоли.
3. **Карточка** — блоки из [`listing.ru.md`](listing.ru.md) как есть: название, краткое и полное описание, иконка
   `icon/icon-512.png`, восемь снимков `screenshots/phone/` по порядку, категория «Симуляторы», возраст 16+, теги,
   сайт https://gornitsa.games/anamnez/, почта support@gornitsa.games, политика
   https://gornitsa.games/privacy.html#anamnez. «Что нового» — только когда загружается версия.
4. **Анкеты** — по [`forms.md`](forms.md), раздел «RuStore»: 16+, данных не собирает, разрешения — вибрация и
   настройки звука, реклама и покупки — нет.
5. **Монетизация.** Бесплатно, без рекламы и покупок (`12-publishing.md` §7). Товаров RuStore Pay не заводить: в
   игре их нет (`src/money/` нет), а релизная сборка — без разрешения `INTERNET` (ADR
   [0006](../docs/adr/0006-offline-no-internet.md)). Покупки — только после 1.0 и отдельной ADR.
6. **Предзаказ** — включить; дата выхода — на выбор владельца, с запасом на ворота 1.0 (ниже). Нужна ли для
   предзаказа загруженная сборка, сколько он может висеть, что получают подписчики при выходе — сверить в консоли:
   документация RuStore из среды разработки недоступна.
7. **Карточка появилась** — прислать агенту ссылку: она встанет в `site/page.ru.md` и `site/page.en.md` (поле
   `links` — кнопка «Предзаказ в RuStore» — и `card.links`) и в `site/press.ru.md` вместо «⟨ссылка⟩».
8. **Ключ API** — «API RuStore» → «Сгенерировать ключ» с доступом к «Анамнезу» в новом кабинете (ключ прежнего
   кабинета сюда не подойдёт). В репозитории: Settings → Secrets and variables → Actions — секрет
   `RUSTORE_API_TOKEN` (приватный ключ, выдаётся один раз) и переменная `RUSTORE_KEY_ID` (номер ключа). Значения —
   только туда, не в Issues и не в чат.
9. **Выход 1.0.** Первая версия — руками через консоль: `anamnez-N.apk` из релиза `v1.0.0`. Со второй — Actions →
   RuStore → Run workflow (`.github/workflows/rustore.yml`): APK из релиза ложится в черновик, на модерацию — галочкой
   «submit» или кнопкой в консоли. API RuStore принимает только вторую и следующие версии
   (`tools/store/rustore.mjs`); `versionCode` должен расти — годится APK из Releases, пересобранный — нет. AAB не
   собирается: RuStore берёт APK.

**Что держит 1.0** (`docs/07-roadmap.md`, «Путь к 1.0»; `docs/12-publishing.md` §8) — решения владельца 20.10.2026:

- сверка базы консультантом — **снята для 1.0**, решение владельца 20.10.2026: «Медицинскую проверку базы

## Что здесь лежит

Всё, что нужно для карточки игры в магазине и страницы на сайте. Правила — право,
медицина, возраст — [`../docs/12-publishing.md`](../docs/12-publishing.md). Тексты,
размеры картинок и запретные слова проверяет `tools/test/store.test.ts`; он же сверяет с базой
числа болезней и травм в текстах: точное число — равно базе, «больше N» — не выше числа в базе.
Для консоли — «больше N»: вставленный текст сам не обновится, а база растёт.

| Файл | Что это | Куда |
|------|---------|------|
| [`listing.ru.md`](listing.ru.md) | название, краткое (≤ 80) и полное (≤ 4000) описание, «Что нового», подписи к снимкам, категория, возраст, теги, контакты | RuStore; сайт |
| [`forms.md`](forms.md) | ответы анкет: возраст 16+ с обоснованием, данные, разрешения, предзаказ; Google Play — после 1.0 | RuStore, Play Console |
| `icon/icon-512.png` | иконка 512 × 512, PNG без прозрачности | RuStore; сайт |
| `screenshots/phone/*.png` | восемь снимков экрана 1080 × 1920 с подписями | RuStore; сайт |
| `graphics/feature-1024x500.png` | графика 1024 × 500 | Google Play; шапка сайта |
| `graphics/cover-1920x1080.png` | обложка: название и два экрана игры | сайт, соцсети |
| `graphics/cover-site-1920x640.png` | обложка над названием на странице игры: план городской больницы без надписей (брендбук студии, 3 : 1) | сайт |
| [`site/page.ru.md`](site/page.ru.md), [`site/page.en.md`](site/page.en.md) | страница игры и карточка на главной: поля и текст по формату устава студии (`docs/08-publishing.md`, «Сайт»); формат проверяет `tools/test/site.test.ts` | gornitsa.games/anamnez — сайт забирает сам раз в сутки (ADR студии 0015) |
| [`site/press.ru.md`](site/press.ru.md) | коротко для прессы и блогеров | по запросу; сайт его не читает |

## Как пересобрать картинки

```bash
npm run export:web && npm run store      # всё: иконки, снимки, графика
npm run store -- --only icons            # только иконки (store/icon и assets/)
```

- **Иконка** — кодом, `tools/store/art.ts`: лупа с лентой ЭКГ в линзе на бирюзовом фоне.
  Этот же знак — иконка приложения на телефоне (`assets/icon.png`, адаптивная и
  монохромная для Android 13+). Красного креста нет: это охраняемая эмблема.
- **Снимки** — настоящая игра в веб-сборке размером телефона 360 × 640 при плотности 3,
  шрифтами игры: ЭКГ — в тёмной теме «Монитор», остальное — в светлой «Медкарте». Графика
  магазина — шрифтом Roboto, по брендбуку студии. Состояния смены пишет движок —
  `tools/store/states.ts`, — поэтому снимки каждый раз одинаковые: районная больница главы 2 на
  третий день — в палатах лежат, идёт операция, скорая везёт больного (с 0.3.0); пневмония на
  снимке; инсульт на КТ в первую смену сосудистого отделения; инфаркт на ЭКГ; разрыв
  Мэллори–Вейсса на ЭГДС в первую смену городской больницы (с 0.5.0 — вместо выбора диагноза);
  готовая амбулатория в песочнице. Подписи — `tools/store/captions.ts`.
- Изменились экраны — пересобрать и посмотреть глазами: подписи не должны закрывать
  интерфейс, а на экранах не должно быть отладочного.

## Требования магазина

Проверено по открытым описаниям консоли RuStore (сентябрь 2026; сама документация RuStore
из среды разработки недоступна — сверить в консоли):

| Что | Требование | У нас |
|-----|------------|-------|
| иконка | PNG 512 × 512, без прозрачности | `icon/icon-512.png` |
| снимки экрана | PNG или JPEG, 1080 × 1920 для телефона; от 4 до 8 рекомендовано, до 10 | 8 штук, 1080 × 1920 |
| краткое описание | до 80 символов | проверяет тест |
| полное описание | до 4000 символов | проверяет тест |
| возраст | по 436-ФЗ | 16+ ([`forms.md`](forms.md)) |
| политика конфиденциальности | ссылка на страницу | единая политика студии https://gornitsa.games/privacy.html#anamnez, раздел «Анамнез» |
