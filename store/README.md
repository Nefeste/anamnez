медицина, возраст — [`../docs/11-publishing.md`](../docs/11-publishing.md). Тексты,
размеры картинок и запретные слова проверяет `tools/test/store.test.ts`.

| Файл | Что это | Куда |

## Как пересобрать картинки

```bash
npm run export:web && npm run store      # всё: иконки, снимки, графика
npm run store -- --only icons            # только иконки (store/icon и assets/)
```

- **Иконка** — кодом, `tools/store/art.ts`: лупа с лентой ЭКГ в линзе на бирюзовом фоне.
  Этот же знак — иконка приложения на телефоне (`assets/icon.png`, адаптивная и
  монохромная для Android 13+). Красного креста нет: это охраняемая эмблема.
- **Снимки** — настоящая игра в веб-сборке размером телефона 360 × 640 при плотности 3,
  шрифтом Roboto, как на Android. Состояния смены (очередь со срочным, пневмония на
  снимке, инфаркт на ЭКГ, итоги третьего дня) пишет движок — `tools/store/states.ts`, —
  поэтому снимки каждый раз одинаковые. Подписи — `tools/store/captions.ts`.
- Изменились экраны — пересобрать и посмотреть глазами: подписи не должны закрывать
  интерфейс, а на экранах не должно быть отладочного.

## Требования магазина

Проверено по открытым описаниям консоли RuStore (сентябрь 2026; сама документация RuStore
из среды разработки недоступна — сверить в консоли):

| Что | Требование | У нас |
|-----|------------|-------|
| иконка | PNG 512 × 512, без прозрачности | `icon/icon-512.png` |
| снимки экрана | PNG или JPEG, 1080 × 1920 для телефона; от 4 до 8 рекомендовано, до 10 | 7 штук, 1080 × 1920 |
| краткое описание | до 80 символов | проверяет тест |
| полное описание | до 4000 символов | проверяет тест |
| возраст | по 436-ФЗ | 16+ ([`forms.md`](forms.md)) |
| политика конфиденциальности | ссылка на страницу | `/anamnez/privacy` на gornitsa.games |
