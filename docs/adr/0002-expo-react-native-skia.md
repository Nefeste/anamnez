# 0002. Expo / React Native / TypeScript, как у «Вотчины»; карта и изображения — Skia

**Решили.** Приложение — Expo (последний стабильный SDK на момент начала: 57, React
Native 0.86; переход на SDK 58 с React Native 0.88 — после его выхода, отдельным
коммитом), React 19, TypeScript, React Compiler, Hermes. Карта больницы, снимки, ЭКГ и
портреты рисуются `@shopify/react-native-skia` (пакетная отрисовка спрайтов через
`Atlas`), жесты и анимация — `react-native-gesture-handler` и `react-native-reanimated`.
Движок, сборка базы, тесты и симулятор — тот же TypeScript под Bun.

**Почему.** Игра на две трети — интерфейс (карта пациента, опрос, бланки, энциклопедия,
профиль, меню) и на треть — живая карта. Сравнивали:

| | Expo / RN + Skia | Godot 4 | Flutter + Flame | Unity | Kotlin + Compose |
|---|---|---|---|---|---|
| интерфейс с текстом, списками, формами | сильная сторона | трудоёмко (Control-узлы, темы) | сильная сторона | средне (UI Toolkit) | сильная сторона |
| 2D-карта с сотнями спрайтов | своими руками на Skia: камера, атлас, пути | из коробки | из коробки (Flame) | из коробки | своими руками |
| перенос пайплайна «Вотчины» (CI без EAS, подпись, RuStore, снимки, i18n, тесты) | целиком | нет | нет | нет | частично |
| один язык для игры, базы, тестов, симулятора | да (TS) | нет (GDScript + скрипты базы) | нет (Dart + скрипты) | нет (C# + скрипты) | да (Kotlin), но без веба |
| веб-сборка для сценариев Playwright | да | тяжёлая | да | тяжёлая | нет |
| ассистент пишет уверенно | лучше всего | заметно хуже (путаница Godot 3/4) | хорошо | хорошо | хорошо |
| лицензия и доступность из РФ | MIT, без ограничений | MIT | BSD | лицензирование из РФ затруднено | Apache |
| опыт владельца | «Вотчина» в магазинах | прототип ClinicSim | нет | нет | нет |

Решает сумма: интерфейсная часть — лучшая у RN; пайплайн до магазинов уже проверен
«Вотчиной» и переносится целиком; движок и база на одном языке с тестами и симулятором;
ассистент на этом стеке самый надёжный. Недостающее от игрового движка — камера,
атлас, пути по сетке, анимация фигурок — для вида сверху на сетке небольшое и
хорошо известное (ADR [0014](0014-top-down-grid.md)).

**Платим.**

- **Главный риск — плавность карты.** По отчётам сообщества, без пакетной отрисовки
  бюджетный телефон начинает терять кадры уже на нескольких сотнях спрайтов; с `Atlas`
  это одно обращение к GPU на текстуру. Слабые телефоны владелец из цели исключил
  (26.09.2026): важно, чтобы не подвисало на современных. Поэтому первый прототип
  этапа 1 — карта с 60 людьми и 600 предметами на современном телефоне
  ([`specs/2026-09-spikes.md`](../specs/2026-09-spikes.md)). Запасной путь, если не
  тянет: упрощённый план без анимации людей (люди — значки в помещениях).
- Игровые вещи (атлас спрайтов, камера, пути, отмена стройки) пишем сами.
- Skia добавляет к APK несколько мегабайт, в вебе — CanvasKit (WASM).
- Expo ломает API от версии к версии — правило «читать версионную документацию, а не
  память» в `AGENTS.md`.

**Что отвергнуто.**

- **Godot.** Лучший 2D, но интерфейс — основная часть игры — на нём дороже, пайплайн
  «Вотчины» не переносится, а база и тесты оказались бы на другом языке. Прототип
  ClinicSim на Godot застрял именно на интерфейсе.
- **Unity** — сложности с лицензированием из России, тяжёлый рантайм для такой игры.
- **Phaser или PixiJS в WebView** — две среды исполнения и медленный мост.

**Когда пересмотреть.** Если прототип карты подвисает на современном телефоне даже с
атласом и записанным полом, а упрощённый план ломает игру, — новая ADR с выбором
Godot для карты или всего приложения. После этапа 2 цена такого решения резко растёт.
