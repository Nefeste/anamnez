# Принятые решения (ADR)

Короткие записки о решениях, которые дорого менять. Каждая отвечает на три вопроса:
что решили, почему, чем за это платим. Формат — как в «Вотчине».

Новая записка — новый файл `NNNN-краткое-название.md` по образцу. Решения не
переписываются задним числом: если передумали, пишется новая записка со ссылкой
«заменяет NNNN», а у старой в заголовке появляется «(заменено NNNN)».
