# 0018. Репозиторий открыт до выхода в магазины

**Решили.** «Анамнез» — отступление от ADR студии
[0017](https://github.com/Nefeste/gornitsa/blob/main/adr/0017-repo-visibility.md), по которому репозитории игр закрыты:
пока идёт активная разработка, репозиторий остаётся открытым — как минимум до выхода в магазины. Решение владельца
10.10.2026 в [#76](https://github.com/Nefeste/anamnez/issues/76): «Пока в активной разработке репозиторий остается
открытым, как минимум до релиза в магазины». Устав разрешает ADR проекта отступать от ADR студии с разрешения владельца
(`docs/04-process.md` устава, «ADR»).

**Почему.**

- В открытом репозитории на бесплатном тарифе GitHub работают наборы правил, защита веток и владельцы кода
  (`CODEOWNERS`); в закрытом их нет без GitHub Pro (ADR студии 0017, «Платим»). Включать ли защиту `main` — вопрос 40,
  [#127](https://github.com/Nefeste/anamnez/issues/127).
- Минуты GitHub Actions у открытого репозитория бесплатны: сборка по тегу, проверки на PR и, если владелец решит,
  симуляторы (вопрос 32, [#121](https://github.com/Nefeste/anamnez/issues/121)) не тратят 2000 общих минут закрытых
  репозиториев студии.
- Сайт забирает страницу игры (`store/site/`) без токена: закрытую игру пришлось бы добавить в его токен только на
  чтение (ADR студии 0015).

**Платим.**

- Виден весь репозиторий с историей: код до выпуска, медицинская база — черновики (`review: draft`; сверка — вопрос 7,
  [#101](https://github.com/Nefeste/anamnez/issues/101)), материалы магазина и `store/forms.md`. Паролей, ключей,
  денежных расчётов и личных данных в нём нет и не будет — так же, как в любом открытом репозитории студии.
- Проект отступает от правила студии: при переходе между проектами это нужно знать.

**Когда пересмотреть.** Перед выходом в магазины (вопрос 8, [#102](https://github.com/Nefeste/anamnez/issues/102)):
закрыть репозиторий по ADR студии 0017 или оставить открытым новым решением владельца.
