# 0006. Игра полностью офлайн: без сервера, учётных записей и разрешения INTERNET

**Решили.** У игры нет сервера, профиля в сети, облачных сохранений, аналитики и
рекламы. В манифесте APK **нет разрешений `INTERNET` и `ACCESS_NETWORK_STATE`** —
CI проверяет это в каждой сборке. Всё, что обычно требует сервера, сделано иначе:

| Что | Как без сервера |
|-----|-----------------|
| «Случай дня», одинаковый у всех | зерно — дата, одинаково у всех с той же версией базы |
| перенос прогресса на другой телефон | автобэкап Android и сохранение в файл через «Поделиться» (`07-data-model.md` §4) |
| отчёт об ошибке | игрок сам отправляет текст почтой или в мессенджере |
| «Поддержать», политика конфиденциальности | ссылки открываются во внешнем браузере — разрешение приложению для этого не нужно |
| обновление базы | вместе с версией игры через магазин |

**Почему.**

- Игра однопользовательская по запросу владельца; сеть ей ничего не даёт.
- **Нечего утечь.** Медицинская тема вызывает вопрос «а что вы собираете?» — ответ
  «приложение не может выйти в сеть» закрывает его одной строкой, и анкеты магазинов
  заполняются честным «нет».
- Ноль рублей на инфраструктуру и ноль обязательств по совместимости протокола
  (у «Вотчины» с 2.0 сервер обязан понимать прошлую версию клиента — ADR 0015 того
  проекта).
- Игра работает в метро, в самолёте и на дежурстве без связи.

**Платим.**

- Нет общих таблиц «Случая дня» и сравнения с другими — только своя серия.
- Исправление базы доходит до игроков только с новой версией игры.
- Сбои не приходят сами: только те отчёты, что игрок отправил. Поэтому переигрывание
  дня по отчёту (`09-testing.md`) — главный инструмент поиска ошибок.
- **Вырезать `INTERNET` можно только из релизной сборки.** Отладочной сборке сеть нужна,
  чтобы брать код у Metro; `blockedPermissions` в `app.json` убрал бы разрешение из обеих.
  Поэтому удаление делает плагин конфигурации, который пишет
  `tools:node="remove"` в манифест варианта `release`; CI проверяет разрешения именно у
  релизных APK и AAB.

**Когда пересмотреть.** Если появится функция, которой без сети нельзя (общая таблица,
облачный прогресс без Google), — новая ADR, новые анкеты и политика; разрешение
добавляется в белый список CI осознанно.
