# 0021. Репозиторий закрывается после публикации 1.0.0

*Заменяет ADR [0018](0018-open-until-stores.md): там — «открыт до выхода в магазины», здесь — что после выхода.*

**Решили.** После публикации 1.0.0 в RuStore репозиторий «Анамнеза» закрывается — по ADR студии
[0017](https://github.com/Nefeste/gornitsa/blob/main/adr/0017-repo-visibility.md), по которому репозитории игр
закрыты. До публикации он открыт, как было решено 10.10.2026 в [#76](https://github.com/Nefeste/anamnez/issues/76):
«Пока в активной разработке репозиторий остается открытым, как минимум до релиза в магазины». Решение владельца
30.10.2026 в [#191](https://github.com/Nefeste/anamnez/issues/191), вопрос 64, — «вариант 1». Видимость меняет
владелец, в настройках репозитория; шаги — `store/README.md`, «Новый кабинет RuStore».

**Почему.**

- Правило студии — закрытые репозитории игр; открытым «Анамнез» был, пока шла разработка до магазинов (ADR 0018).
- Закрыть после публикации, а не сейчас: до выхода PR, сборка по тегу и страница игры на сайте работают как есть, а
  токен сайта готовится к дню закрытия.

**Платим.**

- Проверки на PR (около 10 минут) и сборка по тегу (около 40 минут работы заданий) идут в общие 2000 минут GitHub
  Actions закрытых репозиториев студии.
- Сайт забирает страницу игры (`store/site/`) по токену на чтение (ADR студии 0015): без него страница перестанет
  обновляться. Токен — до закрытия, агент сайта и владелец.
- Защита `main` наборами правил ([#127](https://github.com/Nefeste/anamnez/issues/127)) в закрытом репозитории без
  GitHub Pro не работает (ADR студии 0017, «Платим»); пути владельца держит автослияние по `CODEOWNERS` (ADR
  студии 0018).
- Место под артефакты — общее на закрытые репозитории; сборка его почти не тратит — у неё кэш вместо артефактов
  (`05-process.md`, «Место под артефакты»).
