# 0009. Модель признаков — noisy-OR с полосами частот; у каждого признака есть причина

**Решили.** Связь «состояние → признак» задаётся вероятностью `q` (полосой частоты),
у признака есть «утечка» `λ` — фон популяции. Признак появляется, если его вызвала хотя
бы одна причина (`04-medical-model.md` §4). При генерации для каждой пары бросается
своя монета и **запоминается сработавшая причина**. Отвлекающие признаки возникают
только от настоящих сопутствующих болезней, факторов риска, лечения и фона — никогда
не из общего списка наугад. Обследования наблюдают признаки с чувствительностью и
специфичностью. Вывод для подсказок и разбора — байесовский по той же модели.

**Почему.**

- **Честность.** Прототип добавлял случайные симптомы из общего списка — и загадка
  переставала иметь решение. Здесь у каждого признака есть объяснение, и разбор
  показывает его («кашель — от курения, а не от пневмонии»).
- **Сопутствующие болезни бесплатно.** Курильщик с ХОБЛ кашляет и без пневмонии —
  модель это делает сама, без особых правил.
- **Одна модель на всё.** Генерация пациента, вывод уверенности, польза обследования,
  оценка обоснованности и «виртуальный врач» считаются по одним и тем же числам —
  значит, подсказки и оценка не могут противоречить тому, как рождаются пациенты.
- **Проверенная схема.** «Частота признака при болезни» — основа классических
  диагностических систем (INTERNIST-1/QMR, DXplain); noisy-OR — стандартная
  вероятностная форма такой схемы (QMR-DT).
- **Полосы удобно писать и сверять**: источники чаще говорят «обычно» и «редко», чем
  «73 %».

**Платим.**

- **Условная независимость признаков** при болезни — упрощение. Связанные признаки
  (сторона крепитации и сторона инфильтрата) согласуются через скрытые параметры
  случая; более сложные зависимости модель не выражает.
- Полоса — грубо: «обычно» — это и 60 %, и 90 %. Точное число можно указать только с
  источником.
- Вывод предполагает одно основное заболевание и известные сопутствующие; пациент с
  двумя острыми болезнями сразу (редкость) будет оцениваться по основной.
