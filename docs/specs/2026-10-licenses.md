# Лицензии открытых компонентов

**Версия:** 0.5.6 **Состояние:** сделано

## Зачем

Игра собрана из чужого открытого кода и шрифтов: React Native, Expo, Skia и их библиотеки, шрифты PT и Golos. Их
лицензии разрешают всё, что делает игра, но с условием: назвать авторов и приложить текст лицензии к выпущенной игре.
MIT, BSD и ISC требуют копию уведомления об авторских правах, Apache 2.0 — текст лицензии и файлы NOTICE, OFL — текст
лицензии шрифта, а FreeType, libjpeg и DNG SDK — ещё и строку о себе в документации продукта. В чек-листе перед первой
публикацией (`12-publishing.md` §8) этот пункт был открыт: экрана лицензий в игре не было.

## Что увидит игрок

- **«Об игре» → «Открытые компоненты»**: строка «В игре — шрифты, код и библиотеки других авторов под открытыми
  лицензиями» и кнопка «Лицензии — N».
- **Экран «Лицензии»**: три раздела — «Шрифты», «Код JavaScript», «Библиотеки Android»; с 0.6.6 — и «Звуки», записи под
  CC BY ([`2026-10-clinic-voices.md`](2026-10-clinic-voices.md)). В строке — название и версия,
  лицензия (а у библиотек Android — через что она в игре: React Native, модули Expo, Skia) и правообладатель. Касание
  раскрывает полный текст лицензии; ещё одно — сворачивает.
- Интернет не нужен: тексты — в самой игре.

## Что в списке

- **Код JavaScript** — ровно то, что попало в сборку для Android: пакеты из карты кода сборки (`expo export --platform
  android --source-maps`), 71 пакет. Текст — файл лицензии из каталога пакета. У пакетов монорепозиториев без своего
  файла (`@react-native/*`, `metro-runtime`, `expo-router`, `@expo/ui`) — файл пакета-хозяина с той же лицензией и тем
  же правообладателем; у `standard-navigation` файла нет вовсе — текст MIT с автором из `package.json`.
- **Библиотеки Android** — `tools/licenses/native.yaml`, 39 записей: Hermes и библиотеки C++ React Native (Folly, glog,
  double-conversion, {fmt}, fast_float, Boost), fbjni, SoLoader, Fresco, OkHttp, Okio, zstd, Brotli, Apache Commons,
  Kotlin, AndroidX, Material Components, libc++; Skia ветки m147 и её сторонний код — FreeType, HarfBuzz, libpng, zlib,
  libjpeg-turbo, libwebp, Expat, Wuffs, piex, DNG SDK, cpu-features. Тексты — дословно из источников (`tools/licenses/
  texts/`, ссылка у каждой записи); версии Skia и её библиотек — по коммитам из DEPS ветки chrome/m147.
- **Шрифты** — пять семейств под OFL 1.1, текст — файл рядом со шрифтом (`assets/fonts/`).
- **Звук и музыка** — CC0, упоминания не требуют; авторы и так названы в «Об игре». С 0.6.6 записи под CC BY — в
  разделе «Звуки»: название, автор, ссылка, что изменено и текст лицензии (ADR [0019](../adr/0019-sounds-cc-by.md)).

## Данные

- `src/licenses/licenses.json` — готовый список: группы, записи (название, версия, лицензия SPDX, правообладатель, через
  что в игре, ключи текстов) и тексты по отпечатку — одинаковый текст хранится один раз (74 текста, около 170 КБ).
- Собирает `npm run licenses` (`tools/licenses/build.ts`): сборка для Android во временный каталог, карта кода, пакеты,
  `native.yaml`. Запускать после обновления зависимостей.

## Проверки

- `licenses.test.ts`: готовый файл совпадает с тем, что даёт сборка списка по node_modules и `native.yaml`, — версии и
  тексты нынешние; прямые зависимости игры в списке; лицензии разрешающие (MIT, ISC, BSD, Apache 2.0, BSL, zlib, libpng,
  FTL, IJG, OFL и другие — без копилефта); у каждого — правообладатель и текст; версии нативных библиотек — как в
  `libs.versions.toml` React Native и пакете Skia; библиотеки C++ React Native, группы Gradle из `android/build.gradle`
  модулей сборки и сторонний код в архивах Skia всех ABI — в списке; шрифты из `app.json` — с текстом OFL.
- Сценарий в браузере: «Об игре» → «Лицензии», три раздела, строка Skia раскрывается текстом лицензии; с 0.6.6 —
  четвёртый, «Звуки»: авторы и ссылки записей, у телефона — текст CC BY 4.0.

## Неудачные случаи

- **Обновили зависимость и забыли пересобрать список** — `licenses.test.ts` падает: версия или текст в файле не те.
- **В сборку пришёл новый пакет JS через зависимость зависимости** — тест этого не видит: состав сборки знает только
  карта кода, а сборка идёт полторы минуты. Поэтому `npm run licenses` — в шагах обновления зависимостей (`05-process`).
- **Новая библиотека Android в модуле** — тест сверяет группы Gradle модулей со списком и падает, пока её нет в
  `native.yaml`; транзитивные зависимости Gradle без сборки Gradle не видны — их покрывают группы (AndroidX, Kotlin).

## Чего здесь нет

- **iOS** — игра выходит только на Android.
- **Веб-сборка** (`react-dom`, `react-native-web`) — для сценария в браузере, игрокам она не выдаётся.

## Что изменилось по ходу работы

- В сборку попадает шрифт Material Symbols (967 КБ, Apache 2.0) — через `expo-router` и `expo-symbols`, хотя игра его
  не рисует. В списке он есть (пакет `@expo-google-fonts/material-symbols` и его `LICENSE_FONT`); убрать его из сборки —
  отдельная задача.
