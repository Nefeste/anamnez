# Анамнез

Мобильный симулятор врача с реалистичной диагностикой (рабочее название). К вам идёт
поток пациентов; у каждого — настоящая болезнь, иногда не одна, и почти все её признаки
скрыты, пока вы не спросите, не осмотрите, не назначите анализ или снимок. Вы ставите
диагноз, назначаете лечение, видите исход и разбор случая — а между сменами строите
свою больницу: кабинеты, лабораторию, рентген, УЗИ, КТ, МРТ, операционную, палаты,
закупаете оборудование и нанимаете персонал.

Однопользовательская, без интернета и без рекламы. Android: RuStore и Google Play.
Expo / React Native / TypeScript.

## Состояние

Версия, этап, что дальше и что ждёт владельца — в [`STATUS.md`](STATUS.md); что изменилось для
игрока — в разделах версий ниже.

```bash
npm ci
npm test                             # тесты движка, базы и сохранений (Bun)
npm run doctor                       # «виртуальный врач» по базе
npm run shift-sim                    # темп смены: успевает ли врач принять очередь
npm run economy-sim                  # касса своей амбулатории за 30 дней
npm run district-sim                 # районная и городская больница, карьера с начала
npm run export:web && npm run e2e    # веб-сборка и сценарий по всем экранам
npm run store                        # иконка, снимки и графика для магазина (store/)
npm run android                      # отладочная сборка на телефон или эмулятор
```

### 0.5.9 — дорога по больнице и поломки аппаратов (14.10.2026)

- Расстояния в больнице стоят времени: пациент идёт на снимок, УЗИ, КТ и анализы по коридорам, метр в секунду, — в
  дальний кабинет результат приходит позже, и планировка своей больницы влияет на то, скольких вы примете. К лежащему в
  смотровой приёмного врач идёт сам — и обратно.
- С утра аппарат может не включиться: у большинства — раз в 100 рабочих дней. До конца дня его обследование серым —
  «в ремонте — починят к завтра», на карте смены у кабинета — знак, в журнале смены — строка; есть второй такой аппарат
  — обследование делают на нём. Ремонт — 2 % цены аппарата, в кассе дня. Монитор у постели, наркозный и дыхательный
  аппараты и операционный стол не встают: у них есть запасной. В учебный день главы поломок нет.
- В каталоге аппаратов своей больницы — время обследования, точность и как часто аппарат ломается.
- 90 болезней и 24 травмы; база — версия 75.

### 0.5.8 — дифференциальный ряд и «Ординатор» (14.10.2026)

- В карте пациента — «Гипотезы», ваш дифференциальный ряд, на всех уровнях: болезни, которые вы подозреваете. У
  каждой — что за неё (найденное, что при ней бывает заметно чаще), что против (что она не объясняет и типичное,
  которого нет), что типичное ещё не проверено и каким обследованием это найти, чем подтвердить. Доводы — по той же
  модели, что вывод разумного врача; правды карточка не знает. У «Практиканта» и «Студента» — и «похоже у N из 10»; у
  «Врача» уверенности нет.
- Добавить гипотезу — поиском по болезням больницы или «+ в ряд» у «Похоже на». «Поставить этот диагноз» из карточки
  — сразу к решению; на экране решения ваш ряд — первым.
- Новый уровень сложности «Ординатор» — между «Студентом» и «Врачом»: анализы и осмотр иногда ошибаются, как у врача,
  пациенты ждут чуть дольше, «Похоже на» — до трёх болезней, а уверенность — словами: «едва ли», «маловероятно»,
  «возможно», «вероятно», «почти наверняка».
- 90 болезней и 24 травмы; база — версия 75.
