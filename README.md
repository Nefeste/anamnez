# Анамнез

Мобильный симулятор врача с реалистичной диагностикой (рабочее название). К вам идёт
поток пациентов; у каждого — настоящая болезнь, иногда не одна, и почти все её признаки
скрыты, пока вы не спросите, не осмотрите, не назначите анализ или снимок. Вы ставите
диагноз, назначаете лечение, видите исход и разбор случая — а между сменами строите
свою больницу: кабинеты, лабораторию, рентген, УЗИ, КТ, МРТ, операционную, палаты,
закупаете оборудование и нанимаете персонал.

Однопользовательская, без интернета и без рекламы. Android: RuStore и Google Play.
Expo / React Native / TypeScript.

## Состояние

Версия, этап, что дальше и что ждёт владельца — в [`STATUS.md`](STATUS.md); что изменилось для
игрока — в разделах версий ниже.

```bash
npm ci
npm test                             # тесты движка, базы и сохранений (Bun)
npm run doctor                       # «виртуальный врач» по базе
npm run shift-sim                    # темп смены: успевает ли врач принять очередь
npm run economy-sim                  # касса своей амбулатории за 30 дней
npm run district-sim                 # районная и городская больница, карьера с начала
npm run export:web && npm run e2e    # веб-сборка и сценарий по всем экранам
npm run store                        # иконка, снимки и графика для магазина (store/)
npm run android                      # отладочная сборка на телефон или эмулятор
```

### 0.5.0 — глава 4 «Большая больница» (12.10.2026)

- Глава 4 «Большая больница»: городская больница в вымышленном Верхнеборске — новые больница, штат и касса, как при
  переходе из главы 1 в главу 2. Реанимацию, боксы, эндоскопию и МРТ строите сами, заданиями главы; гастроэнтеролога,
  эндокринолога и инфекциониста нанимаете. Задания: открыть реанимацию, инфекционное отделение и эндоскопию; сто приёмов
  специалистов с точностью от 85 %; антибиотик при сепсисе в срок — три больных подряд; неделя, когда в стационаре умерло
  не больше 2 % лежавших. Письма главного врача и заведующей реанимацией, достижение «Большая больница».
- Первая смена с заведующей реанимацией: септический шок — антибиотик в первый час, посевы, норэпинефрин; рвота кровью —
  ЭГДС в первые 2 часа и гемостаз через эндоскоп; понос с тяжёлым обезвоживанием — в бокс. Заданных больных нанятые врачи
  не берут — они ваши. В «Смене» — городская больница целиком.
- Переход из главы 3 больше не ждёт выписки: лежащих долечат врачи районной больницы.
- С диабетом, гипертонией, гипотиреозом и анемией без своей жалобы приходят на профосмотр; кашель при ГЭРБ — долгий; при
  жалобе на жажду или похудание — глюкоза в лаборатории. Реанимация без ИВЛ стоит как ПИТ; за реанимацию с ИВЛ и бокс ОМС
  платит больше.
- 90 болезней и 24 травмы; база — версия 75.
