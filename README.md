# Анамнез

Мобильный симулятор врача с реалистичной диагностикой (рабочее название). К вам идёт
поток пациентов; у каждого — настоящая болезнь, иногда не одна, и почти все её признаки
скрыты, пока вы не спросите, не осмотрите, не назначите анализ или снимок. Вы ставите
диагноз, назначаете лечение, видите исход и разбор случая — а между сменами строите
свою больницу: кабинеты, лабораторию, рентген, УЗИ, КТ, МРТ, операционную, палаты,
закупаете оборудование и нанимаете персонал.

Однопользовательская, без интернета и без рекламы. Android: RuStore и Google Play.
Expo / React Native / TypeScript.

## Состояние

Версия, этап, что дальше и что ждёт владельца — в [`STATUS.md`](STATUS.md); что изменилось для
игрока — в разделах версий ниже.

```bash
npm ci
npm test                             # тесты движка, базы и сохранений (Bun)
npm run doctor                       # «виртуальный врач» по базе
npm run shift-sim                    # темп смены: успевает ли врач принять очередь
npm run economy-sim                  # касса своей амбулатории за 30 дней
npm run district-sim                 # районная больница глав 2 и 3 и карьера с начала
npm run export:web && npm run e2e    # веб-сборка и сценарий по всем экранам
npm run store                        # иконка, снимки и графика для магазина (store/)
npm run android                      # отладочная сборка на телефон или эмулятор
```

### 0.4.5 — эндокринология, отравления, неврология (12.10.2026)

- Эндокринология: надпочечниковый криз, тиреотоксикоз и тиреотоксический криз, острая гипокальциемия. Криз надпочечников —
  гидрокортизон в вену сразу и солевой раствор в срок; тиамазол — только после ТТГ, а тиреотоксический криз лечат сразу, в
  ПИТ; после операции на щитовидной железе — симптомы Труссо и Хвостека, кальций в вену, на ЭКГ — удлинённый QT.
- Отравления — новая группа диагнозов, лечение — в группе «Антидоты»: опиоиды — налоксон только при лёгкой степени, при
  коме — ИВЛ; угарный газ — кислород через маску; метанол и этиленгликоль — антидот, гидрокарбонат и перевод на гемодиализ.
- Неврология с МРТ позвоночника: радикулопатия, синдром конского хвоста, миастенический криз. Срез позвоночника рисует
  программа; при радикулопатии МРТ в первые недели не нужна, при конском хвосте — экстренная МРТ и перевод; при
  миастеническом кризе — иммуноглобулин в вену, ИВЛ или маска, а фторхинолоны и макролиды опасны.
- Врачи-специалисты: гастроэнтеролог, эндокринолог и инфекционист — нанятые врачи со своей записью, принимают только
  записанных к ним. Нанятый врач не сидит над анализами: пришёл тот, кого он берёт, — отпускает ждущего на обследования.
- 90 болезней и 24 травмы; база — версия 74.
