# Анамнез

Мобильный симулятор врача с реалистичной диагностикой (рабочее название). К вам идёт
поток пациентов; у каждого — настоящая болезнь, иногда не одна, и почти все её признаки
скрыты, пока вы не спросите, не осмотрите, не назначите анализ или снимок. Вы ставите
диагноз, назначаете лечение, видите исход и разбор случая — а между сменами строите
свою больницу: кабинеты, лабораторию, рентген, УЗИ, КТ, МРТ, операционную, палаты,
закупаете оборудование и нанимаете персонал.

Однопользовательская, без интернета и без рекламы. Android: RuStore и Google Play.
Expo / React Native / TypeScript.

## Состояние

Версия, этап, что дальше и что ждёт владельца — в [`STATUS.md`](STATUS.md); что изменилось для
игрока — в разделах версий ниже.

```bash
npm ci
npm test                             # тесты движка, базы и сохранений (Bun)
npm run doctor                       # «виртуальный врач» по базе
npm run shift-sim                    # темп смены: успевает ли врач принять очередь
npm run economy-sim                  # касса своей амбулатории за 30 дней
npm run district-sim                 # районная больница глав 2 и 3 и карьера с начала
npm run export:web && npm run e2e    # веб-сборка и сценарий по всем экранам
npm run store                        # иконка, снимки и графика для магазина (store/)
npm run android                      # отладочная сборка на телефон или эмулятор
```

### 0.4.4 — желудок, кишечник и печень (12.10.2026)

- Эндоскопический кабинет: видеоэндоскоп и эндоскопист. ЭГДС с картинкой — язва, сосуд или сгусток в её дне, кровь,
  разрыв, варикозные вены; при рвоте кровью и чёрном стуле — в первые 2 часа. Кровотечение из язвы по Форресту
  останавливают через эндоскоп, без кабинета — перевод; синдром Мэллори–Вейсса.
- Язвенная болезнь и гастрит с Helicobacter pylori: тест или ЭГДС, ингибитор протонной помпы, при H. pylori — эрадикация.
- Цирроз, асцит и печёночная энцефалопатия: при кровотечении из вен пищевода — вазоактивный препарат и антибиотик до
  ЭГДС, лигирование вен; при напряжённом асците — лечебный парацентез с альбумином, при перитоните — антибиотик и
  альбумин; при энцефалопатии — лактулоза.
- Синдром отмены алкоголя по шкале CIWA-Ar — бензодиазепин, тиамин и психиатр-нарколог; алкогольный гепатит — при
  тяжёлом преднизолон; глюкоза зависимому от алкоголя — только с тиамином.
- Кишечник: сигмоидоскопия и колоноскопия. Тяжёлая атака язвенного колита — глюкокортикоиды в вену, колоноскопия с
  подготовкой опасна. В поликлинике — синдром раздражённого кишечника и функциональный запор.
- Пациент рождается в 2,5–3 раза быстрее.
- 83 болезни и 24 травмы; база — версия 73.
