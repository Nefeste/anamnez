# Анамнез

Мобильный симулятор врача с реалистичной диагностикой (рабочее название). К вам идёт
поток пациентов; у каждого — настоящая болезнь, иногда не одна, и почти все её признаки
скрыты, пока вы не спросите, не осмотрите, не назначите анализ или снимок. Вы ставите
диагноз, назначаете лечение, видите исход и разбор случая — а между сменами строите
свою больницу: кабинеты, лабораторию, рентген, УЗИ, КТ, МРТ, операционную, палаты,
закупаете оборудование и нанимаете персонал.

Однопользовательская, без интернета и без рекламы. Android: RuStore и Google Play.
Expo / React Native / TypeScript.

## Состояние

Версия, этап, что дальше и что ждёт владельца — в [`STATUS.md`](STATUS.md); что изменилось для
игрока — в разделах версий ниже.

```bash
npm ci
npm test                             # тесты движка, базы и сохранений (Bun)
npm run doctor                       # «виртуальный врач» по базе
npm run shift-sim                    # темп смены: успевает ли врач принять очередь
npm run economy-sim                  # касса своей амбулатории за 30 дней
npm run district-sim                 # районная и городская больница, карьера с начала
npm run export:web && npm run e2e    # веб-сборка и сценарий по всем экранам
npm run store                        # иконка, снимки и графика для магазина (store/)
npm run android                      # отладочная сборка на телефон или эмулятор
```

### 0.5.5 — ложные находки по жалобам (14.10.2026)

- Тревожные находки не по жалобам — реже. Осмотр, снимки и ЭКГ ошибаются с частотой из рекомендаций у того, кому они
  показаны по жалобам, у остальных — в 5 раз реже: у пришедшего с кашлем и насморком ложный симптом Мерфи — у 1 из 100,
  а не у 5, «уровни жидкости» на снимке живота у больного мигренью — у 7 из 100, а не у 34. Так же считает разумный
  врач — и уверенность, и пользу обследований.
- В разборе у ложной находки — «находка была ложной: так бывает у N из 100 без болезни».
- В энциклопедии у осмотров, снимков и ЭКГ — что специфичность — у тех, кому обследование показано по жалобам.
- 90 болезней и 24 травмы; база — версия 75.
